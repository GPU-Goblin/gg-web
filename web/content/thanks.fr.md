## Celles et ceux qui participent

- **Les contributeurs**, qui prêtent leur ordinateur : chaque tâche que leur machine calcule sert un
  projet de recherche.
- **Les scientifiques**, qui confient leurs calculs au réseau.
- **Les premiers testeurs**, qui ont essayé GPU Goblin avant tout le monde.

Les comptes ne publient aucun nom. Pour figurer sur cette page, écrivez à
[contact@gpugoblin.com](mailto:contact@gpugoblin.com) en indiquant le nom à afficher.

## Les projets libres

GPU Goblin repose sur le travail de nombreux projets libres, en particulier :

- **Rust** : le langage de tout le logiciel
- **Tokio, reqwest, Axum** : les échanges réseau, côté serveur et côté application
- **Burn, wgpu** : le calcul sur les cartes graphiques avec Vulkan
- **PyTorch, LibTorch** : le calcul avec CUDA, et les modèles des scientifiques
- **PostgreSQL, SQLx** : les données du serveur, crédits compris
- **egui, eframe** : la fenêtre de l'application
- **bubblewrap, Landlock, seccomp** : le bac à sable qui isole chaque tâche
- **ksni, tray-icon** : l'icône dans la zone de notification
- **Inter, Noto** : les polices de caractères (SIL Open Font License)
- **Phosphor** : les icônes de l'application (MIT)
- **Zola** : ce site

Et bien d'autres.
