## Principles

- **No foreign code on your machine.** Contributors run the platform's own code, in a sandbox.
- **Verified results.** Every result is recomputed or compared before it is used.
- **The owner decides.** A machine lends only when and how its owner allows.
- **No money involved.** Credits count contributions; they are not a currency.
