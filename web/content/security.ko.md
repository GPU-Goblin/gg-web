## 여러분의 컴퓨터에서

- **외부 코드 없음.** 소프트웨어는 GPU Goblin 자체 계산 코드만 실행합니다. 작업은 *기술*(모델의 레이어, 데이터 배치, 크기)입니다.
- **작업마다 샌드박스.** {{ <os k="sec_sandbox" lang={lang} win={config.extra.windows_available} /> }}
- **데이터 확인.** 계산을 수행하기 전에, 소프트웨어는 데이터를 받을 때 서버의 서명을 확인합니다. 데이터가 변경되었다면 계산은 거부됩니다.
- **로컬 제어.** 소프트웨어는 여러분 자신의 머신에서만 제어할 수 있습니다.

## 결과에 대해

- **계산 검증.** 각 결과는 독립 검증기가 다시 계산하거나, 서로 다른 두 기여자가 두 번 계산해 측정된 허용 오차 범위 안에서 비교합니다.
- **무작위 점검.** 두 기여자의 결과가 일치하더라도, 결과의 일부를 무작위로 골라 세 번째로 다시 계산합니다.

## 보호하지 못하는 것

- **기여자는 자신이 계산하는 데이터의 조각을 받습니다.** 이름이나 설명이 없는 숫자 배열이며, 각 작업에 필요한 부분뿐입니다. 데이터는 계산 중에 암호화되지 않습니다. 기밀 데이터는 공개 그리드에 보내지 마세요.
- 기여자 간 공유가 켜져 있으면(기본값은 켜짐이며, 끌 수 있습니다) **여러분의 공인 IP 주소가** 같은 데이터에 대한 권한을 받은 다른 머신에 **보입니다**.
