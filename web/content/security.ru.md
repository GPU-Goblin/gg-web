## На вашем компьютере

- **Никакого чужого кода.** Программа выполняет только собственный вычислительный код GPU Goblin.
  Задача — это *описание* (слои модели, пакет данных, размер).
- **Песочница для каждой задачи.** {{ <os k="sec_sandbox" lang={lang} win={config.extra.windows_available} /> }}
- **Проверка данных.** Перед вычислениями программа проверяет подпись сервера при получении данных. Если данные были изменены, вычисление отклоняется.
- **Локальное управление.** Программой можно управлять только с вашего собственного
  компьютера.

## О результатах

- **Проверка вычислений.** Каждый результат либо пересчитывается независимым
  валидатором, либо вычисляется дважды двумя разными участниками и сравнивается в пределах
  измеренного допуска.
- **Выборочные проверки.** Часть результатов случайным образом пересчитывается в третий раз, даже
  если два участника пришли к одному и тому же.

## Что не защищено

- **Участники получают фрагменты данных, которые они вычисляют**: массивы чисел без названий и
  описаний, только то, что нужно каждой задаче. Данные не шифруются во время вычислений: не отправляйте конфиденциальные
  данные в открытую вычислительную сеть.
- **Ваш публичный адрес виден** другим компьютерам, допущенным к тем же данным, когда включён обмен
  между участниками (по умолчанию он включён, и его можно отключить).
