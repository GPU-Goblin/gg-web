GPU Goblin traite aussi peu de données personnelles que possible. Cette page dit lesquelles,
pourquoi, pendant combien de temps, et comment exercer vos droits au titre du Règlement général sur
la protection des données (RGPD).

## Responsable du traitement

Nicolas Michel, éditeur de GPU Goblin — [contact@gpugoblin.com](mailto:contact@gpugoblin.com).

## Données traitées, et pourquoi

| Donnée | Pourquoi | Base légale | Conservation |
|---|---|---|---|
| Votre adresse e-mail | Votre compte : codes de connexion, messages sur le service | Exécution du service que vous demandez | Jusqu'à votre demande de suppression du compte |
| Codes de connexion et sessions (stockés sous forme d'empreinte) | Vous connecter | Exécution du service | Codes 15 minutes, sessions 12 heures |
| Vos machines : nom donné, clé publique, état, tâches calculées, crédits | Faire fonctionner le réseau de calcul et compter les contributions | Exécution du service | Tant que le compte existe |
| Adresse IP publique et port de votre machine | Envoyer les tâches et partager des données entre machines (visible des autres machines autorisées tant que le partage est activé) | Exécution du service | Tant que la machine est active |
| Chercheurs : adresse, laboratoire, projets, données envoyées | Examen des accès et calculs | Exécution du service | Tant que le compte existe ; données de calcul selon les réglages du projet |
| Adresses IP dans les journaux du serveur | Sécurité, prévention des abus | Intérêt légitime | 14 jours |
| Ouverture des e-mails : si un message a été ouvert, et quand | Vérifier que les e-mails arrivent | Intérêt légitime ; sans consentement, comme la CNIL le permet pour cette seule mesure | 3 mois |

GPU Goblin ne vend ni ne loue aucune donnée et n'affiche aucune publicité. Le site **ne vous piste
pas** : ni mesure d'audience, ni script tiers, ni cookie publicitaire. Les e-mails contiennent une
image de suivi, expliquée plus bas.

## Cookies et stockage local

Le site ne dépose aucun cookie. Il garde deux choses dans le stockage local de votre navigateur :
votre choix de thème clair ou sombre et, si vous vous connectez, votre session, pour que vous
restiez connecté. Les deux sont strictement nécessaires à ce que vous avez demandé et sont effacés
quand vous vous déconnectez ou videz les données de votre navigateur.

## E-mails

Les e-mails de GPU Goblin, comme ceux qui contiennent un code de connexion, comportent une petite
image invisible. Votre messagerie la charge depuis les serveurs de Brevo quand elle affiche le
message : comme pour toute image en ligne, Brevo reçoit alors votre adresse IP et le nom de votre
logiciel de messagerie, et enregistre que le message a été ouvert, et quand. GPU Goblin s'en sert
seulement pour vérifier que ses e-mails arrivent, comme le permet la [recommandation de la
CNIL](https://cnil.fr/fr/recommandation-pixel-suivi-courriels), et pour aucun autre usage. Brevo
garde ces informations 3 mois.

Pour l'éviter, bloquez le chargement des images dans votre messagerie : le code reste lisible, car il
fait partie du texte du message.

## Qui reçoit les données

- **OVH SAS** (France), qui héberge les serveurs.
- **Brevo (Sendinblue SAS)** (France), qui achemine les e-mails contenant les codes de connexion et
  enregistre leur ouverture (voir « E-mails »).
- **Les machines des autres contributeurs** reçoivent les données des tâches qu'elles calculent et,
  tant que le partage est activé, l'adresse publique des machines qui partagent les mêmes données.

GPU Goblin ne transfère lui-même aucune donnée hors de l'Union européenne.

## Vos droits

Vous pouvez accéder à vos données, les rectifier ou les effacer, vous opposer à leur traitement ou
le limiter, et en demander une copie : écrivez à
[contact@gpugoblin.com](mailto:contact@gpugoblin.com). Vous pouvez aussi adresser une réclamation à
la [CNIL](https://www.cnil.fr).

La version française de cette politique fait foi.
